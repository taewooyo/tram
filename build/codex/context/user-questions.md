# 사용자 질문과 호스트 입력

사용자에게 결정이나 정보를 요청할 때 메인은 현재 호스트가 제공하는 구조화 질문 도구와 호출 조건을 확인하고, 선택형 결정은 사용 가능하면 실제 도구로 질문한다. 짧은 정보 확인이나 자유 입력도 지원하면 도구를 사용하되 입력이 불편하면 일반 대화를 허용한다. 긴 설명이나 여러 맥락이 필요한 답변은 일반 대화로 받을 수 있으며, 도구의 입력 제한에 맞추려고 질문을 쪼개지 않는다. 진행 상황과 답변이 필요 없는 설명에는 질문 도구를 사용하지 않는다. 텍스트로 선택지를 나열한 것을 네이티브 UI 호출로 간주하지 않는다. 도구의 옵션 개수·라벨·입력 형식과 현재 모드의 제한을 따른다.

선택 가능한 질문은 배경과 영향, 근거 있는 추천을 담고 추천 선택지를 먼저 배치하며 다른 답을 자유롭게 입력할 수 있게 한다. 선택지를 정하기 어려운 질문은 자유 입력을 사용한다. 독립 질문은 소수로 묶고 앞 답변에 의존하는 질문은 답변 후 제시한다. 사용자에게 확인한 사실은 다시 묻지 않으며, 질문 도구의 기본 선택값을 제출된 답으로 취급하지 않는다.

도구가 없거나 현재 모드에서 허용되지 않거나, 필요한 자유 입력을 지원하지 않거나 호출이 실패하면 같은 질문을 일반 대화로 전달하고 답변을 기다린다. PRD·Plan 승인은 검토 대상과 승인 범위를 대화에 명확히 제시한 뒤 가능한 경우 구조화 도구로 승인 여부를 확인한다. 도구 접수·실제 화면 표시·사용자의 응답은 별개다. 실제 확인하지 않은 화면 표시와 응답을 성공으로 보고하지 않는다. 참고 자료 사용이나 개별 질문의 답은 PRD·Plan 승인, 외부 쓰기 권한과 별개이며, 각 승인 대상과 범위에 대한 명시적 응답만 해당 승인으로 기록한다. status는 조회만 하며 질문을 위한 기록이나 상태 전이를 만들지 않는다.
