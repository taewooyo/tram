# 보안 제보 안내

Tram의 보안 문제는 [GitHub 비공개 취약점 제보](https://github.com/taewooyo/tram/security/advisories/new)로 저장소 관리자에게 전달해 주세요. 일반 오류·질문은 [GitHub Issues](https://github.com/taewooyo/tram/issues)를 사용합니다.

공개 이슈에 토큰·인증 파일·환경 변수·대화·검증 출력 원문·사내 자료를 올리지 않습니다. 비공개 제보에도 재현에 필요한 최소 자료만 포함하고 실제 비밀은 제거합니다. 버전·사용 호스트·OS·최소 재현 단계·예상 영향·errorCode를 알려 주세요.

비공개 제보 버튼을 사용할 수 없으면 민감한 상세 내용을 공개하지 말고 일반 이슈로 비공개 연락 경로 확인만 요청해 주세요. 응답 시간과 수정 일정을 보장하지 않습니다.

진단 마스킹은 완전한 비밀 제거를 보장하지 않습니다. 기본 원문 비보존과 로컬 자료 범위는 [운영 안내](docs/operations.md)를 참조하세요.
