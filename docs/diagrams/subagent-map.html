스킬 ↔ 서브에이전트 지도

어느 스킬이 어떤 서브에이전트를 — 왜 — 띄우는가. 보라색 = 내가 만든 커스텀(공유), 파란색 = 에이전트 작업 실행자.

🔗 공유 서브에이전트 = reviewer — /prd · /verify full · /coverage · /retro가 reviewer 역할을 재사용한다. 검토마다 독립 컨텍스트를 사용한다. 행동은 src/agents/reviewer.md 한 곳에, 재료(기준·대상)만 각 스킬이 넘김.
