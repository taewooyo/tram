# Tram 릴리스 검증 기록

`0.0.1/schema 2` 최초 공개 후보에서 확인한 근거와 미검증 범위를 구분한다. Codex·Claude Code용 공개 alpha 준비 중이며 공개 릴리스·전체 호스트 지원 완료를 선언하지 않는다.

버전을 `0.0.1`로 초기화했다. 아래 과거 후보의 실행 기록은 새 공개 후보의 검증 통과를 뜻하지 않는다.

## 의도 중심 작업 경험 개선 · 2026-11-04

- 질문·진행 연결과 승인·문서·재개·완료 안내를 공통 정본에 반영했다. README에 오케스트레이션·실행·런타임 거버넌스와 문서·기록의 경계를 설명했다. 실제 사용자 경험의 개선 폭을 측정한 결과는 아니다.
- 현재 Codex CLI 0.166.0은 ChatGPT 로그인 상태, Claude Code CLI 2.1.92는 미로그인 상태임을 읽기 전용으로 확인했다. 개인 설정·인증정보는 변경하지 않았다. 이번 변경본의 실제 AI 작업·승인·새 세션 재개와 자동 훅 실행은 두 호스트 모두 미검증이다.
- 기존 격리 Codex 설치 cache와 현재 후보를 파일 단위 비교했다. 같은 0.0.1 표시여도 내용이 달라 기존 설치 성공을 이번 변경본의 설치·동작 증거로 재사용할 수 없다. 현재 후보 식별과 비교 자료는 저장소 로컬 검증 자료에 남겼다.
- README를 로컬 HTML로 렌더하고 PNG에서 첫 실행 동선·세 책임 표·기록 표와 하단까지 직접 확인했다. 이는 GitHub 화면이나 실제 호스트 E2E 검증을 대신하지 않는다.
- 이번 세 번째 묶음의 최종 필수 회귀·독립 검증은 별도 실행 결과를 따른다. 실제 행동 비교와 사람 표본 판정은 아직 실행하지 않았다.

## 설명 자산 최신화 · 2026-11-05

`docs/`의 HTML 12개·PNG 14개·SVG 4개를 현재 정본과 대조했다. 필수 interview·한 질문 강제·씨앗 저장 확인으로 이어지던 도식을 조사 후 추천·질문과 선택적 수집 모드로 갱신하고, status 표 안내·승인 스냅샷 보호·읽기 전용 경계를 반영했다. 전문 루프와 브랜드 SVG는 의미가 일치하여 유지했다. HTML 12개를 Chrome으로 렌더해 PNG를 갱신하고 직접 확인했다. README 테마와 SVG 묶음의 하단 잘림은 높이를 늘려 재확인했으며, page PNG 2개는 대응 이미지와 동일성을 확인했다. 이는 설명 자산 대조이며 실제 에이전트 행동·전체 호스트 lifecycle 검증을 대신하지 않는다.

## 호스트 근거 형식 대조 · 2026-11-05

격리 Codex 기준 패키지의 Python fixture에서 실제 두 승인 응답 후 runtime 테스트·리뷰와 완료 상태를 관찰했다. 이는 수정 후보의 전체 lifecycle 통과 기록이 아니다. 절대경로로 실제 호출한 init/status는 기존 수집기에서 인식됐지만 reviewer 생성 관계의 native 증거 검사는 미통과다. 관측된 저장 기록은 `session_meta`·`response_item` 형식이며 spawn 결과는 task_name을 반환한다. 자식 metadata에 부모 UUID가 있어도 현재 어댑터가 요구하는 spawn/wait와 명령 실행의 완전한 연결 근거를 대체하지 않는다. 미지원 형식 진단을 보완하며 기존 검증 문턱은 유지한다. 지원 형식 재검증·후보 업데이트·전체 호스트 행동 평가는 여전히 미완료다.

## 두 호스트 공개 배포 준비 · 2026-11-01

- 공개 저장소 `taewooyo/tram`의 존재·public 상태를 확인했다. 소스·패키지 push·태그·GitHub Release는 아직 실행하지 않았다.
- Apache-2.0을 확정하고 공식 LICENSE 원문을 두 생성 패키지에 포함했다. GitHub 비공개 취약점 제보는 API 활성화 후 `enabled: true`를 확인했다.
- 실제 Codex CLI 0.166.0과 Claude Code CLI 2.1.92에서 저장소 내부 격리 설정으로 로컬 marketplace 등록·설치·목록 조회·제거·재설치에 성공했다. 당시 두 설치 cache의 파일별 동일성을 확인했다. Claude의 `plugin update`는 같은 버전이 최신임을 반환했고 `agents`에서 `tram:reviewer`가 노출됐다. 새 버전 업그레이드·공개 Git 설치·전체 기능 성공을 뜻하지 않는다.
- Claude 기본 계정과 격리 설정 모두 로그인되지 않아 실제 AI 작업 대화·승인·새 세션 재개 검증은 실행하지 못했다. 인증정보를 복사하거나 호스트 인증을 우회하지 않았다.
- 전체 suite: `242 passed` (233.27초, exit 0). 이후 검증 기록·지원 안내·도식 문구를 정리했으며 패키지 계약·빌드·설치 동일성은 최종 동기화 후 별도 확인한다.
- 사용자 중심 README와 두 호스트별 설치·업데이트·첫 사용·제거·기존 `tram-local` 전환 안내를 준비했다. README를 실제 HTML로 렌더하고 도식 HTML 12개·PNG 14개를 갱신·직접 확인했다. 후보 ZIP·checksum은 공개 게시 전 검토용이다.

## 최초 공개 버전 초기화 · 2026-11-01

- 버전은 `0.0.1`, 프로젝트 schema는 2로 유지했다. 기존 PRD·Plan과 CHANGELOG 개발 이력을 정리했다.
- 로컬 전체 테스트: `242 passed` (180.41초, exit 0). 샌드박스 안에서는 프로세스 관찰 제한으로 실패하여 제한 밖에서 재실행한 결과다. 실제 호스트 E2E 검증과 구분한다.
- `python3 scripts/build.py --check`: exit 0. 버전 표기를 수정한 HTML 12개를 Chrome으로 렌더해 PNG 14개를 갱신하고 직접 확인했다.

## 현재 문서 대조 · 2026-11-01

- docs의 설치·지원·운영 안내와 HTML 도식을 현재 runtime·스킬·훅 등록·배포 메타데이터에 대조했다. 최초 공개 버전 초기화와 대상 프로젝트의 새 작업 문서 생성을 구분했다.
- 훅의 도구 matcher·통계 수집 범위와 추가 full 검증 요청 절차를 보완했다. Codex 설치 명령은 공식 패키징·개발자 명령 문서와 대조했다.
- 패키지·스킬 계약·smoke·훅 검사: `52 passed` (35.33초, exit 0). 이번 문서 변경 후 전체 suite는 다시 실행하지 않았으며 위 `242 passed`와 구분한다.
- 변경한 HTML 도식 3개를 Chrome으로 렌더하고 PNG 3개를 직접 확인했다. 로컬 문서 링크와 빌드 일치 검사를 함께 확인한다. 실제 호스트 lifecycle은 여전히 미검증이다.

## 이전 개발 후보의 근거 · 2026-10-29

| 확인 범위 | 관찰 결과 | 한계 |
|---|---|---|
| 준비 상태 안내 기능의 구현 검증 | controller task complete, full 독립 리뷰 100/100; round 1의 tests·build-check exit 0, stale=false | 해당 기능 검증 snapshot의 결과. 이후 공개 문서 정리의 검증 결과로 재사용하지 않음 |
| 전체 suite 직접 실행의 이전 snapshot | 242 passed | 현재 문서 정리 후 재실행 결과가 아니며 host E2E 증거가 아님 |
| Codex 격리 실제 대화 | init에서 선택형 지식 조사 생략, quick 변경, HEAD 변경 후 재검증 안내, 읽기 전용 PR 준비 조회를 확인 | CLI 일부 시나리오. Desktop UI 자동 플러그인 로드·전체 기능 lifecycle은 미검증 |
| Codex 설치·스킬 노출 | `tram-local` 등록 및 설치 스킬 노출 확인, 설치 버전 `0.2.1`은 사용자 보고 | 현재 후보와 설치 cache의 최신 파일별 동일성은 미확인 |
| 실제 프로젝트 연결 | Android 연결·Gradle 성공 사용자 보고 | 원본 실행 로그를 직접 확인한 결과가 아니며 full 기능 흐름·훅·Kover 성공을 뜻하지 않음 |
| 후보·설치본 hash 대조 | 과거 snapshot에서 일치 확인 뒤, 문서 변경으로 불일치 관찰 | 현재 설치 cache의 동일성 근거로 재사용하지 않음 |
| 패키지·fixture 회귀 | Codex/Claude 생성 패키지와 Python/Node fixture 검사 이력 | 실제 에이전트 설치·대화·native lifecycle의 대체 증거가 아님 |

이 표는 기존 실행 기록의 요약이다. 테스트·빌드·설명 자산을 변경한 뒤에는 해당 snapshot에서 다시 확인해야 한다. 조회의 `ready`와 버전 표시는 검증 통과·패키지 동일성·작업 완료를 뜻하지 않는다.

## 문서·설명 자산 정리 · 2026-10-29

일회성 동기화 문서를 배포 목록에서 제거하고 설치·지원·운영 안내를 사용자 중심으로 정리했다. HTML 12개와 PNG 14개를 갱신했으며 Chrome 렌더 16회와 모든 PNG의 직접 확인을 수행했다. coverage·성능 도식의 하단 잘림을 수정했다. SVG 4개와 배너 GIF는 설명 의미 변화가 없어 보존했다. 당시 개발 세션·개인 설정·PRD/Plan 스냅샷은 로컬에 보존하고 공개 Git 대상에서 제외했다. 이후 2026-11-01 최초 공개 버전 초기화에서 기존 PRD·Plan 26개를 삭제했다. 구현 코드·스킬·테스트는 유지한다.
