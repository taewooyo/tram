위임 경계 — light는 직접 실행 가능, full은 fresh reviewer의 실제 검사·독립 대조를 유지한다. 작업자는 재위임하지 않는다. 직접 수행·재개 기준은 Task·위임·재개 · 구현 카드 · 검증 카드.산출물 — 대상 프로젝트 소스·테스트·빌드 설정.
저위험 경로 — /quick → 직접 또는 위임 변경·테스트 → /verify light. 풀 흐름은 PRD 확정·Plan 승인 후 구현한다.
TRAM라우터 · 빌드 디스패처 · /verify
의도를 지키는 진행 · 확인한 사실은 재질문하지 않는다. 추천·대안·영향을 제시하며 필요한 결정을 묻고, 복잡하면 interview를 수집 도구로 선택한다. 추천은 사용자 답변과 구분한다.
상태·문서 · status는 목록·상세 표로 승인·검증 유효성·막힌 이유·다음 행동을 안내한다. 기존 문서만 링크하며 승인 스냅샷과 조회 기록을 수정하지 않는다. 단계 명령을 반복 요구하지 않는다.
