실행 주체는 [단일 오케스트레이션 계약](../../context/start-experience.md)의 직접 수행·위임 기준을 따른다. 아래 작업자 절차는 위임 시 적용하며 각 경로의 독립 검토·안전판은 유지한다.

## 실행 경계

현재 스킬 파일의 `../..`를 plugin root로 해석하고 `<plugin-root>/adapter.md`와 [공통 실행 계약](../../context/runtime-contract.md)을 먼저 읽는다. 대상 프로젝트는 사용자 지정 경로로 명시하며 plugin root와 혼동하지 않는다. 문서·명령의 상대 경로와 셸 cwd는 대상 프로젝트 기준이다. `<plugin-root>` 표기는 해석한 실제 경로로 치환하고 셸 경로는 인용한다. Native 도구·독립 검토 호출은 adapter를 따른다.


## 실행 역할

[단일 오케스트레이션 계약](../../context/start-experience.md)을 따른다. 메인은 이 스킬 전체 흐름을 읽고 직접 수행 또는 단계 배정을 선택하며 작업자는 사용자 질문·승인/전이·Task 갱신·재위임을 하지 않는다. 작업자가 기존 로그를 읽기 전용으로 집계·분석하고 메인이 결과를 전달한다. 조회를 위해 로그·Task·새 runtime route를 만들지 않는다.

# /skill-stat — 스킬 호출 통계

PreToolUse 훅이 `.tram/local/logs/skill-usage.log` 에 기록한 스킬 호출 내역을 집계해
보기 좋게 보여줍니다. (로그 한 줄 = 호출 1회, 형식: `시각<TAB>스킬명`)

전달된 인자: `$skill-stat` 뒤의 사용자 메시지.
- 인자가 없으면 → 전체 통계
- 특정 스킬명이 주어지면 → 그 스킬만 필터링해서 통계

---

## 진행 순서

### 1단계: 로그 존재 확인

작업자가 프로젝트 루트를 실행 도구의 `workdir`로 지정해 읽기 전용으로 실행한다.

```bash
test -f ".tram/local/logs/skill-usage.log"
```

파일이 없으면 legacy `.codex/skill-usage.log`를 조회 입력으로만 확인한다. 둘 다 없으면 기록이 없음을 안내하고 종료한다. 훅 지원·활성화는 adapter에서 확인하며 조회 중 로그를 생성하지 않는다. 두 로그가 있으면 출처별로 집계해 같은 호출을 중복 합산하지 않는다.

### 2단계: 집계 (한 번에 실행)

작업자가 아래 명령들로 핵심 수치를 모으고 출처·원시 집계·제한을 메인에 반환한다.

```bash
LOG=".tram/local/logs/skill-usage.log"
if [ ! -f "$LOG" ]; then LOG=".codex/skill-usage.log"; fi

# 총 호출 횟수
wc -l < "$LOG"

# 스킬별 호출 횟수 (많은 순)
cut -f2 "$LOG" | sort | uniq -c | sort -rn

# 최근 호출 5건
tail -n 5 "$LOG"

# 오늘 호출 횟수 (선택) — 오늘 날짜로 시작하는 줄 수
#   날짜는 환경에 주어진 현재 날짜를 사용하거나 무시 가능
```

### 3단계: 표로 정리해 보고

메인이 작업자의 집계 결과를 다음 형태로 사람이 읽기 좋게 출력한다:

```
📊 스킬 호출 통계

총 호출: N건   (서로 다른 스킬 M종)

순위  스킬            호출 수   비율
 1    commit            12     50%
 2    skill-stat         7     29%
 3    deep-research      5     21%

최근 호출:
  2026-06-25 14:03  commit
  2026-06-25 13:50  skill-stat
  ...
```

- 비율은 (해당 스킬 횟수 / 총 호출) 로 계산한다.
- 막대(▇)를 곁들여 시각적으로 표현하면 더 좋다.

### 4단계: 가벼운 인사이트 (선택)

작업자가 가장 많이 쓴 스킬, 거의 안 쓰는 스킬 등 근거 있는 분석을 반환하면 메인이 한두 줄로 짚어준다.
과한 분석은 피하고 데이터에 근거한 것만 말한다.

## 참고
- 로그 파일은 `.gitignore` 에 포함되어 커밋되지 않는 개인 사용 기록이다.
- 기록은 adapter가 지원하는 native 호출·prompt 훅이 담당한다. 별도 Skill 도구가 존재한다고 가정하지 않는다. 통계가 비어 있으면 adapter의 훅 지원·활성화 상태를 확인한다.
- 로그 경로는 **상대경로**(`.tram/local/logs/skill-usage.log`)로 읽는다 — `exec_command`의 `workdir`를 프로젝트 루트로 지정한다. 훅용 프로젝트 환경변수가 일반 도구 셸에도 채워져 있다고 가정하지 않는다.
