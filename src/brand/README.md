# Tram 브랜드 자산

한지 트램·세 정거장·이어진 경로로 Tram을 표현하며 README와 향후 웹·데스크톱 앱에서 같은 원본을 재사용한다.

## 브랜드 의미

- 한지 트램: 아이디어를 접어 구체적인 결과로 만드는 과정과 Tram이라는 이름.
- 세 조약돌 정거장: 요구사항 확정·계획 승인·결과 검증.
- 이어진 경로: 승인한 방향을 유지하며 세션을 넘어 작업을 이어가는 흐름.

## 자산 선택

| 용도 | 파일 |
| --- | --- |
| 원본 브랜드 장면 | `tram-light-master.png`·`tram-dark-master.png` (1254×1254) |
| README·웹의 작은 아이콘 | `light/tram-128.png`·`light/tram-256.png`, 다크 테마는 `dark/`의 같은 크기 |
| 웹·향후 앱의 고해상도 아이콘 | `light/tram-1024.png`·`dark/tram-1024.png` |
| 향후 macOS 앱 | `tram-light.icns`·`tram-dark.icns` |
| 향후 Windows 앱·웹 favicon 후보 | `tram-light.ico`·`tram-dark.ico` |
| 웹·소개 페이지의 가로 장면 | `tram-hero-light.png` (1536×1024, 왼쪽 제목 여백) |

`light/`와 `dark/`에는 각각 16·32·48·64·128·256·512·1024px PNG가 있다. 크기별 파일은 원본을 축소한 자산이며 작은 크기에서 정거장·종이 질감의 표현은 줄어든다. README는 GitHub 테마에 따라 라이트·다크 PNG를 선택한다.

## 사용 기준

원본 비율을 유지하고 트램·경로·세 정거장을 하나의 구성으로 사용한다. 라이트와 다크는 같은 브랜드의 별도 생성 이미지이며 픽셀 단위로 동일하지 않다. 정사각형 PNG는 불투명 원본이며 앱의 모서리 마스크는 대상 플랫폼에서 적용한다. 투명 시안은 가장자리 잔여 픽셀이 있어 최종 자산에서 제외했다.

ICNS·ICO는 향후 앱 프로젝트에 전달할 자산이다. 현재 Tram에 데스크톱 앱·웹 서비스가 구현됐다는 뜻은 아니다. 실제 Dock·작업 표시줄·모바일 마스크와 favicon의 작은 크기 식별성은 대상 앱·웹에 연결할 때 확인한다. 에이전트 플러그인의 실행 패키지에는 브랜드 원본을 추가하지 않는다.

## 재생성

원본 이미지와 [생성 프롬프트](prompts.md)를 보존한다. PNG 크기와 ICNS·ICO를 다시 내보내려면 macOS의 `sips`와 Python 3을 사용한다.

```bash
python3 src/brand/export.py
```

[export.py](export.py)는 원본 장면을 다시 그리지 않고 크기·컨테이너만 생성한다. 재생성 후에는 README 테마와 실제 적용할 아이콘 크기로 직접 확인한다.
